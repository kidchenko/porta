How it knows

Porta asks the OS which processes are listening on TCP ports: GetExtendedTcpTable on Windows, lsof on macOS. Then it reads each one's command line, working folder and start time.

A server is yours when a shell or terminal is among its parents: Terminal, iTerm2, Ghostty, Windows Terminal, VS Code's terminal and so on. The rest is filed under other apps and services.

Stopping asks nicely first. On macOS a server gets a SIGTERM so it can shut down cleanly, with Force quit if it won't. Porta never offers to stop the OS's own processes, and nothing it sees leaves your computer.

From a terminal

The same answers without opening the menu.

$ porta list
  3000  node     41859  2h 05m   LAN    terminal  shop
  5173  node     42210  14m      local  terminal  docs
  5432  postgres   917  3d 01h   local
$ porta stop 3000
Stopped node (pid 41859) on 3000.
